# 🤖 Арбитражный Монитор с Telegram Ботом

## 📋 Описание

Мониторинг арбитражных возможностей на фьючерсных биржах с уведомлениями в Telegram. Система исключает проблемные токены и показывает только качественные возможности.

## 🏦 Поддерживаемые биржи

- **Bybit Futures** ✅
- **Bitget Futures** ✅
- **Gate.io Futures** ✅
- **MEXC Futures** ✅
- **Binance Futures** ✅
- **Huobi Futures** ✅

## 🚀 Быстрый старт

### 1. Установка зависимостей:

```bash
pip install -r requirements.txt
```

### 2. Запуск монитора:

```bash
python futures_arbitrage_blacklist.py
```

### 3. Настройка Telegram:

1. Найдите бота: `@vashkaBOT` или по токену `YOUR_BOT_TOKEN_HERE`
2. Отправьте `/start` для подписки
3. Получайте уведомления о возможностях > 5%

## 📱 Команды Telegram бота

- `/start` - Подписаться на уведомления
- `/stop` - Отписаться от уведомлений
- `/status` - Показать статус
- `/help` - Показать справку

## ⚙️ Настройки

### Конфигурация через файл:

Все настройки находятся в файле `config.py`:

```python
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# Monitoring Settings
MIN_PROFIT = 0.1              # Минимальная прибыль для отображения
TELEGRAM_MIN_PROFIT = 5.0     # Минимальная прибыль для Telegram
UPDATE_INTERVAL = 5            # Интервал обновления (секунды)

# Logging Settings
LOG_FILE = "arbitrage_log.txt"
USERS_FILE = "telegram_users.json"
BLACKLIST_FILE = "coin_blacklist.json"
```

### Настройка токена:

1. Откройте файл `config.py`
2. Замените `YOUR_BOT_TOKEN_HERE` на ваш токен бота:
   ```python
   TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН_БОТА_ЗДЕСЬ"
   ```
3. Сохраните файл
4. Запустите: `python futures_arbitrage_blacklist.py`

## 🛠️ Устранение неполадок

### Нет уведомлений:

1. Убедитесь, что отправили `/start` боту
2. Проверьте, что прибыль > 5%
3. Убедитесь, что монета не в черном списке

### Ошибки API:

1. Проверьте интернет соединение
2. Перезапустите скрипт
3. Проверьте логи в `arbitrage_log.txt`

### Проблемы с ботом:

1. Проверьте токен бота
2. Убедитесь, что бот запущен
3. Используйте `python test_bot.py` для тестирования
