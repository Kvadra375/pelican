# 🚀 Команды для работы с арбитражным монитором

## 🎯 Основные команды

### Запуск монитора:

```bash
python futures_arbitrage_blacklist.py
```

### Простой запуск:

```bash
python run_blacklist.py
```

### Управление черным списком:

```bash
python manage_blacklist.py
```

### Проверка черного списка:

```bash
python coin_blacklist.py
```

## 🤖 Telegram команды

### В боте (@vashkaBOT):

- `/start` - Подписаться на уведомления
- `/stop` - Отписаться от уведомлений
- `/status` - Показать статус
- `/help` - Показать справку

### Получение chat_id:

```bash
python get_chat_id.py
```

## 🚫 Управление черным списком

### Меню управления:

```bash
python manage_blacklist.py
```

**Опции:**

1. Показать черный список
2. Добавить монету в черный список
3. Удалить монету из черного списка
4. Проверить монету
5. Статистика
6. Очистить черный список
7. Выход

## ⚙️ Настройка токена Telegram бота

**Токен:** `YOUR_BOT_TOKEN_HERE`

**Расположение:** В файле `config.py`:

```python
TELEGRAM_BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```

**Создание своей конфигурации:**

1. Скопируйте `config_example.py` в `config.py`
2. Замените токен на свой
3. Настройте другие параметры

## 🛑 Остановка

- **Ctrl+C** - корректная остановка
- **Ctrl+Break** - принудительная остановка

## 📝 Логи

Все действия записываются в `arbitrage_log.txt`
