# ⚙️ Настройка проекта

## 🔐 Настройка токена Telegram бота

### 1. Создайте файл конфигурации:

```bash
cp config_example.py config.py
```

### 2. Отредактируйте config.py:

```python
# Замените YOUR_BOT_TOKEN_HERE на ваш токен
TELEGRAM_BOT_TOKEN = "YOUR_ACTUAL_BOT_TOKEN_HERE"
```

### 3. Получите токен бота:

1. Найдите @BotFather в Telegram
2. Отправьте `/newbot` или `/mybots`
3. Следуйте инструкциям для создания/получения токена
4. Скопируйте токен в config.py

## 🚀 Запуск

### После настройки config.py:

```bash
python futures_arbitrage_blacklist.py
```

### В Telegram:

1. Найдите вашего бота по токену
2. Отправьте `/start`
3. Получайте уведомления!
